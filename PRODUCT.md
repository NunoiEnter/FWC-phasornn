# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain static HTML, Tailwind CSS utilities, custom CSS, and vanilla JavaScript. No JavaScript framework.

## Users

The primary users are peer evaluators and visitors reviewing a two-person 42 Discovery Piscine Rush submission.

## Product Purpose

Present a responsive three-page mini showcase: one route-selection page leading to two individual portfolio pages.

## Positioning

The team portfolio behaves like a compact visual novel: visitors choose a teammate's route, then read that person's profile as a chapter.

## Operating Context

The project is opened directly from the `discovery_piscine/rush` folder and may be reviewed on desktop or mobile during a peer defense.

## Capabilities and Constraints

- Exactly three HTML pages: a team summary and two portfolio pages.
- Each portfolio includes an always-visible navigation bar, About, Showcase, and Contact sections.
- Tailwind CSS is used only as CSS. All interaction code is vanilla JavaScript.
- The final `auteur` file contains two 42 logins, one per line, with a trailing newline.
- Personal details for the second teammate are still open and are clearly isolated as replaceable placeholders.

## Brand Commitments

The user requested a visual-novel theme and the simplest clean implementation possible.

## Product Principles

- Make both portfolio routes discoverable immediately.
- Keep the required sections obvious to peer evaluators.
- Reuse one shared visual system and minimal JavaScript.
- Treat unconfirmed personal data as editable placeholders, never invented facts.
